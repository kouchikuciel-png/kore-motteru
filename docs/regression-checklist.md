# 回帰テストチェックリスト

初号機で既に通った機能を、次の変更で壊さないための実機確認項目。

## 1. オーナー登録

- [ ] 未登録の本を読むと登録候補になる
- [ ] 読み取り後にタイトル・著者が表示される
- [ ] 表紙候補が取得できる本では表紙が表示される
- [ ] 表紙が取得できない場合でも登録操作は継続できる
- [ ] 書誌情報が見つからない本でもISBN読取成功は失敗扱いにせず、そのまま登録できる
- [ ] 書誌情報が見つからない場合は白いダミー表紙を出さず、📚と「本の番号は読み取れています。このまま登録できます。」を表示する
- [ ] 数量の初期値は1
- [ ] `−` で1未満にならない
- [ ] `＋` で追加数量を増やせる
- [ ] 確定した数量だけ在庫へ加算される

既知の境界テスト:

- `9784141992776`（藤田智の新・野菜づくり大全）: 現行の主要書誌取得元でタイトルが取れない場合がある。ISBN登録そのものは継続でき、白いダミー表紙を成功扱いしないこと。

## 2. 重複登録

- [ ] 登録済みの本を読むと「同じものを登録しますか？」になる
- [ ] 現在の所有数量が表示される
- [ ] 追加数量は現在数量ではなく「今回追加する数量」として扱われる
- [ ] 追加後の所有数量が正しく増える

## 3. 日本の書籍2段バーコード

- [ ] `978...` / `979...` の有効なISBNだけを本の識別子として採用する
- [ ] `192...` の価格・分類側バーコードは登録候補にしない
- [ ] 2本が同時に映っても読み取りが停止し続けない
- [ ] 読み取り枠外のコードに引っ張られない

## 4. ISBN文字認識

- [ ] `ISBN978-...` の印字を正規化してISBN-13として扱える
- [ ] 旧ISBN-10を読み取った場合は正しいISBN-13へ変換できる
- [ ] 変換後もバーコード読取と同じ登録UIへ合流する

## 5. 表紙取得

- [ ] 少なくとも複数の既知本で表紙が実機表示される
- [ ] 表紙成功時は診断UIを表示しない
- [ ] 全候補失敗時だけ「表紙診断を見る」を表示する
- [ ] 診断には候補数、img-error、HTTP status、content-typeが残る
- [ ] 表紙失敗でタイトル・著者・登録機能まで失敗扱いにしない

## 6. ゲスト側

- [ ] 共有リンクから登録済み一覧を表示できる
- [ ] 所有数量が正しく見える
- [ ] バーコード確認で所有数量・購入予定数量を取得できる
- [ ] 重複していても購入予定への追加を禁止しない
- [ ] ゲストから既存在庫の削除・減算はできない

## 7. 権限境界

- [ ] OWNERトークンとSHOPトークンは別のまま
- [ ] ゲスト画面からオーナー権限へ昇格できない
- [ ] ブラウザから家庭テーブルを直接読む実装を追加していない
- [ ] RPC経由の既存境界を維持する

## 8. iPhone実機

- [ ] Safariでカメラ起動
- [ ] カメラ停止後に再度読み取りを始められる
- [ ] 連続して別の本を読める
- [ ] ダークモードでも文字・ボタンが見える
- [ ] チュートリアルを閉じたあと登録操作へ戻れる

## 判定

新機能の追加前後でこの表を通し、既存GREENを壊していないことを確認する。
表紙は1冊だけの成功ではGREEN固定せず、複数冊で再現できた時点で安定GREENへ昇格する。
