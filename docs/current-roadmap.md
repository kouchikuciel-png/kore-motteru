# 現在地と次工程

## 現在地

本の登録ラインは、読み取り・書誌情報・数量指定・重複加算まで実機で前進している。

表紙取得は実機で複数冊の表示成功を確認した。

- ケチャップマン2
- 崖の上のポニョ
- 探偵ガリレオ

さらに、既登録の「崖の上のポニョ」では現在所有数量 ×1 を正しく表示し、そのまま追加数量UIへ進めた。
未登録の「探偵ガリレオ」でも表紙・タイトル・著者を表示して新規登録UIへ進めた。

このため、表紙取得と本登録の基本導線は安定GREENとして扱い、今後は新しい不具合が出ない限り読み取り・表紙ロジックを不用意に変更しない。

役割は次で固定する。

- オーナーモード: 家庭在庫を作る。新規登録と既存在庫への数量追加ができる。
- ゲストモード: 家庭在庫を参照する。所有確認・購入予定への追加・「渡した」の記録ができる。自分の呼ばれ方を登録し、購入者・贈り主として来歴に残せる。
- 「渡した」は受け取り待ちを作るだけで、在庫はまだ増やさない。
- オーナーが「受け取った」を押した時だけ在庫へ加算する。
- ゲストは在庫の直接追加・削除・減算をしない。

## 裁可なしで進める範囲

既存仕様を変えず、壊れにくくする作業は自律進行する。

- オーナー / ゲストの表示を明確にする
- 既存画面の文言・タップ領域・読みやすさを整える
- 回帰テストを固定する
- 表紙失敗時の診断を成功時には隠す
- 一覧カードの見え方を統一する
- README / 設計資料 / 現在地を更新する
- 既存GREENを壊していないか確認する

## 次の裁可ポイント

以下はデータの意味・権限・主要UXを変えるため、実装前に裁可を取る。

### 1. ゲストの「追加」の意味（裁可済み）

次で固定する。

`購入予定 → 渡した（受け取り待ち） → 受け取った → 在庫`

ゲストは在庫を直接変更しない。実際に渡した事実を登録し、オーナーの受取確認で初めて在庫へ反映する。

### 2. スクショ / 手入力での「持ってる？」確認

候補:

- 商品名検索
- スクショOCR
- バーコード番号の直接入力
- 複数候補が出た時の選択方法

### 3. 在庫の減算・削除

決めること:

- オーナーだけに許可するか
- 誤操作防止をどうするか
- 履歴を必須にするか

## 次の受入ゲート

まず本だけで次の一周を成立させる。

`読む → 登録 → 一覧で確認 → もう一度読む → 重複を確認 → 数量を追加`

現在、読み取り・書誌情報・表紙表示・重複検知・追加数量UIまでは実機で通っている。
残る確認は、登録後の一覧反映と、同じ本への数量追加が最後まで正しく保存されること。

このループと「渡した → 受け取った → 在庫」の受け渡しループ、さらに「誰が買った / 誰から来た」の来歴表示が安定したら、ゲストの検索・スクショ確認へ進む。
その後に牛乳・卵など一般商品の在庫へ構造を転用する。


## 裁可済み: ゲスト名と本の来歴

- ゲストはこの家庭での自分の呼ばれ方を登録する
- 購入予定には購入者名を残す
- 受け渡しには贈り主名を残す
- 受取確定後も来歴を削除せず、所有一覧・詳細から確認できるようにする
- 現時点では購入者と贈り主が同じゲストなら同じ名前を使うが、DB上は別概念として保持できる構造にする


## 裁可済み: 来歴表示のON/OFF

- 来歴データは常に保持する
- 初回だけオーナーが「表示する / 表示しない」を選ぶ
- あとからいつでも変更できる
- 未選択・非表示時はゲストの本棚へ来歴を出さない
- 「誰から来たか」を見せる自由と、見せない自由を両方残す


## 2026-09-21: 受け渡し衝突と取消

出先でも進められる範囲として、次を初版の安全仕様へ追加する。

- 同じISBNに受け取り待ちがある状態でオーナーが読むと、通常登録より先に受け取り待ちを提示する
- 「受け取った」= 受け取り待ち数量を在庫へ加算
- 「この分はもう登録済み」= 在庫を増やさず、受け取り待ちと既存在庫を来歴としてひもづける
- 「別の1冊として追加する」= 受け取り待ちは残し、本当に別の冊として追加する
- ゲストは自分が作った未受取の「渡した」を取り消せる
- オーナーも未受取を取り消せる
- 取消時は、この受け渡しで消費した購入予定を可能な範囲で元へ戻す
- 受取済みは取消対象にしない

これにより「同じISBN」だけで重複判定せず、「同じ出来事か / 本当に別の1冊か」を人に確認してから在庫を変える。

## 初版までの残件

端末なしで進められる実装・DB・資料整備は継続する。
実機が必要な残件は次。

- オーナー実機: 新規登録 → 一覧 → 再読取 → 数量追加
- オーナー実機: 受け取り待ち本を読んだ時の3択
- ゲスト実機: 名前 → 購入予定 → 渡した → 取消
- 来歴表示 ON/OFF の画面確認
- Android実機で共有リンク・カメラ・保存名・受け渡しを一周
