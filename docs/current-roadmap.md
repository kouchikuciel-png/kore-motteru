# 現在地と次工程

## 現在地

本の登録ラインは、読み取り・書誌情報・数量指定・重複加算まで実機で前進している。
表紙は実機で少なくとも1冊の表示成功を確認したため、次は複数冊で再現性を確認して安定GREEN判定する。

役割は次で固定する。

- オーナーモード: 家庭在庫を作る。新規登録と既存在庫への数量追加ができる。
- ゲストモード: 家庭在庫を参照する。所有確認と購入予定への追加ができる。
- ゲストは在庫の削除・減算をしない。

## 裁可なしで進める範囲

既存仕様を変えず、壊れにくくする作業は自律進行する。

- オーナー / ゲストの表示を明確にする
- 既存画面の文言・タップ領域・読みやすさを整える
- 回帰テストを固定する
- 表紙失敗時の診断を成功時には隠す
- 一覧カードの見え方を統一する
- README / 設計資料 / 現在地を更新する
- 既存GREENを壊していないか確認する

## 次の裁可ポイント

以下はデータの意味・権限・主要UXを変えるため、実装前に裁可を取る。

### 1. ゲストの「追加」の意味

候補:

- 購入予定だけを追加する
- 実在庫そのものを追加できる
- 購入完了操作を経由して在庫へ反映する

### 2. スクショ / 手入力での「持ってる？」確認

候補:

- 商品名検索
- スクショOCR
- バーコード番号の直接入力
- 複数候補が出た時の選択方法

### 3. 在庫の減算・削除

決めること:

- オーナーだけに許可するか
- 誤操作防止をどうするか
- 履歴を必須にするか

## 次の受入ゲート

まず本だけで次の一周を成立させる。

`読む → 登録 → 一覧で確認 → もう一度読む → 重複を確認 → 数量を追加`

このループが安定したら、ゲストの検索・スクショ確認へ進む。
その後に牛乳・卵など一般商品の在庫へ構造を転用する。
