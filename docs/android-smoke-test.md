# Android 初版スモークテスト

新井さんの実利用前に、Android実機で最低限ここだけ通す。

## ゲスト

1. SHOP共有リンクをChromeで開く
2. 「この家では、なんて呼ばれていますか？」に呼ばれ方を保存
3. ページを閉じて再訪し、呼ばれ方が復元される
4. 所有一覧が表示される
5. バーコード確認を起動し、カメラ権限を許可
6. 所有数量・購入予定数量が表示される
7. 購入予定へ追加
8. 「渡した」を実行
9. 「あなたが渡したもの」に表示される
10. 一度「渡したを取り消す」を試し、購入予定が戻ることを確認
11. 再度「渡した」を実行して受け取り待ちを作る

## オーナー

1. OWNERリンクをAndroid Chromeで開く
2. 受け取り待ちが表示される
3. 「受け取った」で在庫へ反映
4. 同じ依頼を再実行しても二重加算されない
5. 来歴表示をONにし、ゲスト一覧で「○○から」が見える
6. OFFにし、来歴だけが非表示になる
7. 再度ONにして来歴が戻る

## 衝突確認

同じISBNで受け取り待ちを作り、オーナー側で同じ本を読む。

- 「受け取った」: 受け取り待ち数量を在庫へ加算
- 「この分はもう登録済み」: 在庫数量を変えず受取完了
- 「別の1冊として追加する」: 受け取り待ちを残し、別の冊として登録

## 合格条件

- 画面が崩れない
- 戻る操作で詰まらない
- カメラを再起動できる
- 名前・購入予定・受け渡し・在庫・来歴の状態がページ再読込後も維持される
- 同じ出来事で在庫が二重に増えない
