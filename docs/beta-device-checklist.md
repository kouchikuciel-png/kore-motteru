# 初版β 実機確認手順（iPhone / Android）

新井さんへ渡す前に、自動テストでは確かめられない部分を実機で一周確認する。
既存の `docs/regression-checklist.md` と `docs/android-smoke-test.md` を、出荷前の手順としてまとめ直したもの。

## 準備

- 端末A（オーナー）: OWNERリンクを開ける端末
- 端末B（ゲスト）: 別の端末。iPhone（Safari）と Android（Chrome）の両方で1回ずつ通す
- 本を3冊用意する
  - 本1: 未登録で、表紙が出やすい本
  - 本2: 日本の書籍で2段バーコードがある本（下段が `192…`）
  - 本3: 書誌情報が取れにくい本（例: `9784141992776`）
- 操作前に、ページを再読み込みして最新版を読み込む（index.html / owner.html の `?v=20260924-audit1` が効いていること）

確認用データは本番の家庭に残る。**削除機能は無いので、実際に持っている本だけで試す。**

## 1. オーナー: 登録（端末A）

| # | 操作 | 期待結果 | iPhone | Android |
|---|---|---|---|---|
| 1-1 | OWNERリンクを開く | 「オーナーモード」表示。初回は使い方と来歴表示の選択が出る | ☐ | ☐ |
| 1-2 | 「カメラで登録する」→ カメラ許可 | カメラが起動する | ☐ | ☐ |
| 1-3 | 本1のISBNバーコードを読む | 「読み取りました」。タイトル・著者・表紙が表示され、数量が1 | ☐ | ☐ |
| 1-4 | ＋で3にして「登録する」 | 「所有数量 ×3」 | ☐ | ☐ |
| 1-5 | 本1をもう一度読む | 「同じものを登録しますか？」と現在数量 ×3 | ☐ | ☐ |
| 1-6 | 追加数量2で「追加する」 | 「所有数量 ×3 → ×5」 | ☐ | ☐ |
| 1-7 | 本2の下段（192…）だけを映す | 枠が赤くなり「別のバーコードです」。登録画面へ進まず、カメラも止まらない | ☐ | ☐ |
| 1-8 | そのまま上段（978…）へ動かす | ISBN側で数量UIへ進む | ☐ | ☐ |
| 1-9 | 本2をバーコード無しで、ISBN印字だけ映す（指で隠す等） | 数秒で文字認識し、同じ数量UIへ進む | ☐ | ☐ |
| 1-10 | 本3を読む | 表紙が無くても📚と「このまま登録できます」。白いダミー表紙が出ない | ☐ | ☐ |
| 1-11 | 「番号を入力する」に `9784198625734`（チェック桁違い）を入力 | 登録せずエラー表示 | ☐ | ☐ |
| 1-12 | 登録後「別のものを読み取る」を3回繰り返す | 毎回カメラが再起動する | ☐ | ☐ |

## 3. ゲスト: QR招待と呼び名（端末B）

| # | 操作 | 期待結果 | iPhone | Android |
|---|---|---|---|---|
| 3-1 | 端末Bの標準カメラで「じいじ」QRを読む | ゲスト画面が開き「この家では「じいじ」として登録されています」 | ☐ | ☐ |
| 3-2 | QRのスクショを別ブラウザ（またはプライベートタブ）で開く | 入力なしで同じ「じいじ」が復元される | ☐ | ☐ |
| 3-3 | 空欄QRを読む | 「このQRの初回登録です」。呼び名を入力して保存 | ☐ | ☐ |
| 3-4 | 3-3のページを閉じて再度開く | 入力欄がロックされ、保存した呼び名が表示される | ☐ | ☐ |
| 3-5 | 端末Aの一覧を再読み込み | 3-3の呼び名が一覧に出る | ☐ | ☐ |
| 3-6 | 端末Aで呼び名を変更（⋯ →「名前変更」） | 端末Bを再読み込みすると新しい呼び名になる | ☐ | ☐ |

## 4. ゲスト: 所有確認・重複・購入予定・渡した（端末B）

| # | 操作 | 期待結果 | iPhone | Android |
|---|---|---|---|---|
| 4-1 | 「持ってるもの」一覧を見る | 本1が ×5 で表示。表紙が出る（出なければ📚） | ☐ | ☐ |
| 4-2 | 一覧の本1をタップ | 詳細が開き、同じ表紙・数量 | ☐ | ☐ |
| 4-3 | 「バーコードで確認する」で本1を読む | 「重複しています」、すでに持っている 5 | ☐ | ☐ |
| 4-4 | 本2の下段（192…）を映す | 「本の番号ではありません」と案内され、照合しない（今回修正） | ☐ | ☐ |
| 4-5 | 数量2で「それでも購入予定に入れる」 | 「じいじの購入予定として、数量 2」 | ☐ | ☐ |
| 4-6 | もう一度本1を読み「渡した」（数量1） | 「「渡した」を知らせました」。在庫はまだ増えない | ☐ | ☐ |
| 4-7 | ページを再読み込み | 「あなたが渡したもの」に 4-6 が表示される（今回修正） | ☐ | ☐ |
| 4-8 | 「「渡した」を取り消す」 | 一覧から消える。購入予定が戻る | ☐ | ☐ |
| 4-9 | もう一度「渡した」を行う | 受け取り待ちが作られる | ☐ | ☐ |

## 5. オーナー: 受け取りと来歴（端末A）

| # | 操作 | 期待結果 | iPhone | Android |
|---|---|---|---|---|
| 5-1 | OWNERリンクを再読み込み | 「受け取り待ち」に「じいじから・数量 ×1」 | ☐ | ☐ |
| 5-2 | 本1を読む | 通常登録より先に「受け取り待ちの本です」と3択が出る | ☐ | ☐ |
| 5-3 | 「受け取った」 | 「所有数量 ×5 → ×6」 | ☐ | ☐ |
| 5-4 | 受け取り待ち一覧を確認し、本1をもう一度読む | 受け取り待ちから消え、通常の「同じものを登録しますか？」（×6）になる。勝手に増えない | ☐ | ☐ |
| 5-5 | 来歴表示を「表示する」 | 端末Bの一覧・詳細に「じいじから」 | ☐ | ☐ |
| 5-6 | 来歴表示を「表示しない」 | 端末Bから来歴だけ消える（数量は変わらない） | ☐ | ☐ |

## 6. 無効化と権限

| # | 操作 | 期待結果 | iPhone | Android |
|---|---|---|---|---|
| 6-1 | 端末Aで「じいじ」を無効化（⋯ →「無効」） | 一覧から消える | ☐ | ☐ |
| 6-2 | 端末Bで「じいじ」のリンクを再読み込み | 「一覧を読み込めませんでした。共有リンクを確認してください。」 | ☐ | ☐ |
| 6-3 | ゲストのリンクの `index.html` を `owner.html` に書き換えて開く | 登録・受け取りができない（「家主リンクが無効です」等） | ☐ | ☐ |

## 7. 端末共通

- [ ] ダークモードで文字・ボタンが読める（両OS）
- [ ] 画面の横はみ出し・スクロール詰まりがない
- [ ] 戻る操作（ブラウザの戻る / 「← 持ってるもの」）で詰まらない
- [ ] 回線を切った状態で操作すると「通信状態を確認して…」が出て、データが壊れない
- [ ] iPhone: ホーム画面に追加した状態でもカメラが起動する（使う予定がある場合のみ）

## 記録

不具合があれば、端末・OS・ブラウザ・手順番号・画面のスクショを残す。
表紙が出ない場合は、オーナー画面の「表紙診断を見る」を開いてスクショする。
